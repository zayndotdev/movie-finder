# 🎬 CineMatch — AI-Powered Movie Finder

> **Find your perfect movie, powered by AI.**  
> Describe your mood, vibe, or exact taste — CineMatch finds the movies you'll love from Bollywood, Hollywood, and beyond.

---

## 🌟 What is CineMatch?

CineMatch is an intelligent, AI-powered movie discovery platform that goes far beyond simple search. Tell it how you're feeling, describe the kind of story you want, or filter by specific actors, ratings, genres, and languages — and CineMatch's AI agent will scour the internet to find exactly the right movie for you.

Whether you want a heartwarming Bollywood romance, an edge-of-your-seat Hollywood thriller, a critically acclaimed Korean drama, or an underrated indie gem — CineMatch finds it.

---

## 🚀 Features

- 🧠 **AI-Powered Mood Search** — Describe your mood in natural language and get personalized recommendations
- 🎭 **Multi-Filter Discovery** — Filter by genre, rating, actor, director, language, year, and more
- 🌍 **Global Cinema** — Bollywood, Hollywood, Korean, Japanese, European, and regional cinema
- 🎬 **Trailer Previews** — Watch trailers directly within the app
- 📍 **Where to Watch** — Find streaming availability across platforms in your region
- ⭐ **Aggregated Ratings** — Scores from TMDB, IMDb, and more
- 🔥 **Trending & Popular** — See what's hot right now
- 📋 **Smart Watchlists** — Save movies to watch later
- 🎯 **Similar Movies** — Get recommendations based on movies you love
- 🎞️ **Cast & Crew Deep Dive** — Explore filmographies of actors and directors

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | React + TypeScript + Vite |
| **Styling** | TailwindCSS v4 |
| **Backend** | Node.js + Express + TypeScript |
| **AI Engine** | Google Gemini API (Free Tier) + Groq API |
| **Movie Data** | TMDB API (The Movie Database) |
| **Deployment** | Vercel (Free Tier) |

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/zayndotdev/movie-finder.git

# Install dependencies
cd movie-finder
npm install

# Set up environment variables
cp .env.example .env

# Start development server
npm run dev
```
